# ProductInfoCore V0.1.0

Programmneutraler Core für Zutaten, Big-14-Allergene, Zusatzstoffe, Nährwerte, Quellen, Versionierung und Freigabestatus. Nur freigegebene Datensätze dürfen in Verkäuferoberflächen publiziert werden. Fehlende Angaben bleiben `not-checked` und werden niemals als allergenfrei interpretiert.
