# SalesInventoryAnalysisCore V0.1.0

Programmneutraler Auswertungskern für Umsatz, Kunden/Bons, Tages- und
Uhrzeitvergleiche sowie die zentrale Bestandsrechnung.

Der PC-Manager führt Anfangsbestände, Nachkäufe und Korrekturen. Nach einem
Kassenabgleich werden nur bestätigte Verbrauchsregeln automatisch abgezogen.
Unbekannte Werte werden nicht geschätzt, sondern als „Messung erforderlich“
gekennzeichnet. An Kasse und Verkaufsstand entsteht keine Inventurpflicht.
