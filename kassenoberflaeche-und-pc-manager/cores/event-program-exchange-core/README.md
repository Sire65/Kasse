# EventProgramExchangeCore

Zentraler, fachlich begrenzter Austausch-Core für bewertete Tagesprogramme zwischen PC-Manager und Kasse.

- Studio-ID: `EventProgramExchangeCore`
- Runtime-ID: `shared.event-program.exchange`
- Runtime: `shared/event-program-exchange-core-v010.js`
- Format: `KC_EVENT_PROGRAM_PACKAGE_V1` (`.kcprogram`)
- Status: Candidate; statischer TÜV bestanden, praktischer Kassentest offen

Der Core darf Programm, Bewertung sowie optional Wetter- und Personalhinweise übertragen. Artikel, Preise, Bons, Transaktionen, Kassenstatus, Benutzer und Rechte sind ausdrücklich ausgeschlossen.
