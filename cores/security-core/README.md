# SecurityCore V0.2.0

Zentrale rollen- und fähigkeitsbasierte Autorisierung. Verborgene Oberflächen sind **kein** Sicherheitsmechanismus; jede geschützte Aktion wird zusätzlich zur UI technisch geprüft.

Rollen: Verkäufer, Schichtleitung, Manager, Admin, SuperAdmin.

Eigenschaften: deny-by-default, Schritt-hoch-Authentifizierung, Begründungspflicht, direkte Funktionsaufrufe geschützt.
