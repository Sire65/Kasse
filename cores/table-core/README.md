# TableCore V1.1.0

Zentraler, produktneutraler Datenkern aus Framework Studio V1.38.39.

Der PC-Manager bindet ihn ausschließlich über `manager-table-core.js` an seine
fachlichen Tabellen. Der Adapter verändert keine Artikeldaten, Rezeptdaten oder
sonstige Fachlogik. Tabellen innerhalb von TV-Bühnen und QR-Ausgaben werden
nicht angebunden.

Unterstützte Bedienung:

- auf- und absteigend sortieren sowie Ursprungssortierung wiederherstellen,
- Spalten mit dem Anfasser verschieben,
- Spalten per `Alt` + Pfeiltaste verschieben,
- Spaltenbreite mit Maus oder Touch ändern,
- Doppelklick am Spaltenrand für Auto-Fit,
- Reihenfolge, Breiten und Sortierung lokal je Tabelle erhalten.
