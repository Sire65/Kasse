# AudioPresentationCore 0.1.0

Zentrale Hintergrund-Audiosteuerung für Präsentationen. Unterstützt Musik und Sprache, Lautstärke, Schleife und automatische Wiedergabe. MP3-Dateien liegen getrennt unter `media/audio/music/` oder `media/audio/speech/` und werden über `media/audio/audio-library.json` registriert.
