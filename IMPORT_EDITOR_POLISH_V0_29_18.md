# KC MarktKasse V0.29.18 – Import & Editor Polish

Additive Änderungen ohne Entfernung bestehender Funktionen:

- sichtbarer Mülleimer auf jeder Mini-Folie mit Sicherheitsabfrage
- technische Korrektur: kein verschachtelter Button mehr
- Textfelder werden während der Direkteingabe ausreichend breit geöffnet
- besserer Kontrast der Vorschau- und Navigationstasten
- „Excel-Tabelle“ ersetzt durch „Import / Datei einfügen“
- universeller Import für Text, Tabellen, Fotos, Dokumente und Videos
- Assistent für Mitglieder-Fotofolien „Der Köcheclub stellt sich vor“
- Assistent für Weihnachtsmarkt-Programm: heute, morgen, übermorgen
- vorhandener Excel-Tabellenimport bleibt vollständig erhalten

Hinweis: BMP ist das übliche Windows-Bitmapformat; „MBP“ wurde als BMP interpretiert.
