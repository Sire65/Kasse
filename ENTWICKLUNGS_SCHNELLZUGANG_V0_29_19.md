# Entwicklungs-Schnellzugang V0.29.19

Temporäre Funktion für die Entwicklungs- und Testphase.

## Bedienung

1. Manager öffnen.
2. Im Dialog „Manager entsperren“ doppelt auf die Überschrift klicken.
3. Der Manager wird für die aktuelle Browsersitzung ohne PIN freigegeben.

## Sicherheitsverhalten

- Der gespeicherte Master-PIN wird nicht verändert oder gelöscht.
- Es wird kein Bypass in LocalStorage oder einer Datei gespeichert.
- Nach Neuladen oder Schließen der Seite ist der Manager wieder gesperrt.
- Ein sichtbares Entwicklungs-Banner weist auf den aktiven Schnellzugang hin.
- Die Erweiterung ist vor einer Produktivfreigabe vollständig zu entfernen.
