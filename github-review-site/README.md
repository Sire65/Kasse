# KC Präsentationsprüfung

Den Inhalt dieses Ordners in ein eigenes GitHub-Repository hochladen. Unter **Settings → Pages** als Quelle **GitHub Actions** wählen. Die Seite enthält nur die Präsentation und die lokale Freigabefunktion, nicht den PC-Manager oder Kassendaten.

Bewertungen werden im Browser gespeichert. Mit **Rückmeldung herunterladen** entsteht eine JSON-Datei, die an den Köcheclub zurückgesendet werden kann.
