KC MARKTKASSE – START HIER
Stand: 13.11.2026

WELCHE STARTDATEI?
- Am Stand (Mini-PC mit Tablets und Fernseher): KC_Manager_Start.cmd
- Zu Hause (nur mitlesen/steuern ueber Supabase):  KC_Zuhause_Start.cmd
  Ausfuehrlich: KONZEPT_STAND_ZUHAUSE.md
- Mini-PC am Stand einmalig vorbereiten: KC_MiniPC_Einrichten.cmd
  (Fernseher/Praesentation: TABLET_UND_MANAGER_KOPPELN.md, Abschnitt E1)

NORMALER START (Stand)
1. ZIP vollständig entpacken.
2. KC_Manager_Start.cmd doppelklicken.
3. Beim allerersten Start Internetverbindung zulassen.
4. Das schwarze Startfenster während des Betriebs geöffnet lassen.
5. Der PC-Manager öffnet sich automatisch im Standardbrowser.

ERSTER START
Falls die portable Laufzeit noch nicht im Ordner liegt, startet automatisch KC_Einrichtung.ps1.
Die Einrichtung:
- lädt Node.js 22.22.3 als portable Windows-Laufzeit,
- prüft die offizielle SHA-256-Prüfsumme von nodejs.org,
- installiert die benötigten Module ws, bonjour-service und selfsigned,
- speichert alles innerhalb dieses KC-Ordners.

Nach erfolgreichem ersten Start kann diese Installation im selben entpackten Ordner weiterverwendet werden. Für den lokalen Start ist dann keine erneute Installation erforderlich.

GESTARTET WERDEN
- Manager-/Kassen-Dienst auf HTTPS-Port 8543,
- lokaler Webserver auf Port 8090,
- drei Tablet-Kassen KASSE-01/02/03 auf den festen Ports 47500/47501/47502,
- PC-Manager im Browser.

TABLETS (seit 13.11.2026): jedes Tablet wird EINMAL mit einem gedruckten QR-Zettel gekoppelt,
danach nie wieder gescannt. Zettel drucken: PC-Manager -> Verbindung pruefen -> QR-Zettel.
Ausfuehrlich: TABLET_UND_MANAGER_KOPPELN.md
Am Ende des Starts steht "[Marktag-Start] ALLES BEREIT" - oder "BEREIT MIT WARNUNGEN" mit der
genauen Ursache darueber.

WICHTIG
- Nicht direkt pc-manager\index.html per Doppelklick öffnen.
- Nicht das schwarze Startfenster schließen, solange PC-Manager/Kassen arbeiten.
- Bei belegtem Port 8090 wird 15 s gewartet und dann auf den nächsten freien Port ausgewichen - mit Warnung, weil die Tablet-Zettel auf 8090 zeigen.
- Browserdateien werden mit No-Cache ausgeliefert, damit keine alte JS-Version hängen bleibt.

Beenden: Strg+C im schwarzen Startfenster.
