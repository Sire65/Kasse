# ExchangeCore V0.30.2

Neutrale, minimierte Austauschverträge für KC Bildrechner.

- `KCB-CONFIG-1`: nur benötigte Konfigurationsdaten
- `KCB-EVENT-1`: nur benötigte Vorgangsdaten
- `KCB-CASH-1`: nur benötigte Bargeldübergabedaten
- `exchange-filter.js`: Positivlisten und Feldbereinigung zur Laufzeit

Unbekannte Felder werden nicht übernommen. Kryptografische Signaturen folgen in V0.30.3.
